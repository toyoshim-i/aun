# E008: WCET Cycle Budget Exceeded

A function annotated with `#[budget(...)]` has a statically computed worst-case T-state count exceeding its declared limit.

## Recommended Fixes

1. **Tighten loop bounds**: ensure `#[max_iters(N)]` reflects the true upper bound on bounded loops.
2. **Annotate `extern "asm"` contracts**: supply accurate `wcet(N)` on called `extern "asm"` functions so the analyzer does not assume a conservative fallback.
3. **Optimize hot paths in idiomatic Aun**:
   - Use `#[align(256)]` on lookup tables and small struct arrays (`stride * len <= 256`).
   - Use `#[smc]` on singleton state machines for 10T direct-JP dispatch.
   - Prefer `u8`/`u16` arithmetic over `u32` inside inner loops.
4. **Targeted `extern "asm"`**: if the measured hot inner loop still cannot meet the hardware deadline (e.g., VBlank/HBlank ISR), move only that loop into `extern "asm"` with an explicit `wcet(...)` contract.
