# W001: Unused Function or Global Eliminated at Link Time

When building a whole-program binary (`--format bin`), Aun computes reachability from true entry roots (`main`, `#[export_name]`, ISRs, `on_swap`, `overlay_slot` loaders, FSM hooks, and symbols referenced by external `.s` modules).

Any function (including `pub fn` used only for cross-module visibility in `.aun`) or `const` / `static` global that is unreachable from those roots is automatically removed at link time, and `W001` reports the item and bytes reclaimed.

## What To Do

- **If it is dead/demo code**: delete the unused function or data from your `.aun` source to keep the codebase clean.
- **If it must be callable from external assembly**: give it an explicit `#[export_name("...")]` or reference its symbol from your `.s` file.
- **In `--format sdasz80` library mode**: `pub` symbols are preserved as external linker entry points and are not eliminated by `W001`.
