# E003: Register-Explicit FFI (`extern "asm"`) and SDCC `--sdcccall 1`

## `extern "asm"` Signatures and `clobbers(...)`

- Every parameter and return value requires a hardware register or `stack` binding (`in A`, `in HL`, `in DE`, `in L`, `in stack`).
- **Omitted `clobbers(...)`** conservatively assumes the callee clobbers caller-saved `AF, BC, DE, HL` (matches SDCC `--sdcccall 1` C functions).
- **Explicit `clobbers()`** tells the register allocator the routine preserves all registers (including `B`/`C`/`BC`), enabling whole-program `BC`/`C` allocation across calls.

```aun
extern "asm" {
    fn _hal_opn_write(reg: u8 in A, val: u8 in L) clobbers(A, B, D, F);
    fn _hal_enter_crit() clobbers();
}
```

## Exported `pub fn` C ABI (`--format sdasz80`)

- 2-argument `(u16, u8)` functions receive `(HL, stack 1B)` with 1-byte callee cleanup in SDCC `--sdcccall 1`.
- 16-bit `pub fn` returns are converted to `DE` in the `_name::` wrapper.

See [Z80 Backend and ABI](../z80-backend.md) and [Aun Language Reference](../language-reference.md).
