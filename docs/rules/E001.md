# E001: Mixed-Width and Overflowing Arithmetic

Aun never performs implicit C-style integer promotions. Both operands of arithmetic (`+`, `-`, `*`, `&`, `|`, `^`) and comparisons must have identical widths and signedness.

## Operator Suffixes

- **Checked (default)**: `+`, `-`, `*`, `/`, `%` — traps with `PanicCode::Overflow` in debug builds on overflow.
- **Wrapping**: `+%`, `-%`, `*%` — wraps modulo $2^W$ cleanly in both debug and release.
- **Saturating**: `+|`, `-|`, `*|` — clamps at `[min, max]` without wrapping.

## Fix Example

```aun
let a: u8 = 200u8;
let b: u16 = 300u16;
let sum: u16 = (a as u16) +% b;
```
