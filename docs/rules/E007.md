# E007: RAM and Stack Budget Overflow

This error occurs when:
- Allocated RAM (`static mut` globals, state buffers, and Uchiguri scratch frames) overlaps a `stack` window or exceeds its `space` upper bound, or
- Computed worst-case static stack depth exceeds the target `stack` budget.

## Diagnose First with `--memory-report`

Run `aun build --memory-report ...` (succeeds in printing the full RAM/stack layout even on overflow) to see the largest globals, state buffers, and frame sizes.

## Recommended Fixes

1. **Make scene-local buffers state-scoped**: move top-level `static mut` buffers that are only needed in one scene into `state S { static mut BUF: ...; }` (with `#[zero_on_enter]` if zero-initialization is needed) so sibling states overlap in RAM via Uchiguri.
2. **Remove dead/demo `static mut` globals**: check `warning[W001]` and `--memory-report`.
3. **Move large buffers to another `space` or `bank`** (e.g., `static mut BUF: [u8; 1024] in HighMainRam;`).
4. **Reduce stack depth**: flatten deeply nested call chains or split large functions so fewer registers/call frames are live simultaneously.

See [Memory & Overlay Budget Optimization Playbook](../memory-optimization.md) (`aun guide memory-optimization`) and [Target Definitions and Uchiguri RAM](../target-and-memory.md).
