# E002: Second-Class References and Borrow Aliasing

Aun uses **second-class references (AD-3)** so every local frame can be allocated statically by *Uchiguri* without general pointer escape or heap lifetimes:

- `&T`, `&mut T`, and `&[T]` / `&mut [T]` are valid **only** as function parameters or temporary local bindings.
- They cannot appear inside `struct` fields, `static` globals, or function return types (`-> &T`).
- At call sites, passing two references that alias the same root object with at least one `&mut` is rejected, **except** disjoint struct fields (e.g. `step(&mut s.a, &s.b)` is allowed).

## Workarounds

- Pass indices, handles (`Handle<T>` for `Pool<T, N>`), or mutate through a single `&mut Parent` reference.
- Read/copy values via locals instead of returning `&T`.

See [Aun Language Reference](../language-reference.md) for borrow and pool semantics.
